# 制作圣经（Production Bible）：人物 · 造型 · 道具 · 场景 · 声线

> 剧本是短剧制作的地基：AI 短剧里**每一个人物、每一套衣服、每一件道具、每一个场景都是一张要生成、要锁定的参考图**，每一个有台词的角色都是一条要选定的声线。剧本写到哪里，资产就要做到哪里。
> 制作圣经 = 一份 `adaptation/bible.json`，是全剧唯一真源：编剧用它保持人物一致，美术用它生图，声音用它选声，下游视频管线直接导入。
> 何时做：L2 压缩决策之后、L4 分集大纲定稿之前起草；L5 每写一批剧本就更新（新造型、新道具、状态变化）。

---

## 一、四层人物档案

一个角色要同时回答四个部门的问题：

| 层 | 给谁用 | 字段 | 写法要点 |
| :--- | :--- | :--- | :--- |
| **戏剧层** | 编剧 | `role` `want` `need` `misbelief` `arc` `pressure_choices` `contradiction` `first_entrance` | 见 `character-and-dialogue.md` |
| **语言层** | 编剧/配音 | `voice_sheet`：`rhythm` `vocabulary` `catchphrases` `never_says` `tells` | 每个主角 3 条口头禅以内；写"绝不会说的话"比写"会说的话"更能锁住人设 |
| **视觉层** | 美术/生图 | `gender`；`visual`：`age` `height` `build` `face` `hair` `skin` `signature` + **`en`（一句英文外貌，直接进生图提示词）**；`wardrobe`（造型 ID 列表） | 只写镜头看得见的；**每个主角一个标志性视觉符号**（红痣、旧手绳） |
| **声音层** | 配音/选声 | `voice_casting`：`tier` `timbre` `pitch` `pace` `accent` `age_anchor` `reference` + `en`（英文控制词） | 用可听辨的词（低沉、气声、语速慢），不写"好听" |
| 表演层（可选） | 导演/视频提示词 | `acting`：`engine` `body` `eyes` `tics` | 每个主角 2–3 个习惯动作，写清触发条件 |

**配角/客串**只要：`role`、一句 `want`、一个 `signature`、一个造型、`voice_casting` 一行。不要给客串写小传——资产越少越好。

---

## 二、ID 规则（与 h3-drama-kit 资产库兼容）

| 类 | 规则 | 例 |
| :--- | :--- | :--- |
| 人物 | `C01`…（主角从 C01 起） | `C01` Wren |
| 造型 | `<人物ID>-<造型名>`，**同一人换衣服/换状态 = 新 ID** | `C01-SHARK`（灰卫衣+鲨鱼拖鞋）、`C01-GALA`、`C02-SUIT`、`C02-WET`（暴雨湿透） |
| 道具 | `P01`…；**完整/损坏/带血是不同资产** | `P05` 旧手绳、`P05B` L&W 金扣新手绳 |
| 场景 | `<D/N/R>-<地点>`：白天/夜晚/雨天分开 | `N-AURELIAN-HALL`、`D-AURELIAN-HALL`、`R-SAWMILL` |

一个造型 ID 对应一张参考图。剧本里写名字即可，`bible.json` 用 `aliases` 把名字映射到 ID。

---

## 三、造型（Wardrobe）——最容易失控的成本

- **按"阶段"设计，不按"场次"**：主角全剧 6–10 套造型足够。每多一套 = 多一张参考图、多一次一致性风险。
- 造型只写参考图上看得见的东西（颜色、材质、版型、鞋），不写品牌情绪词。
- **状态变化单独成 ID**：淋湿、受伤、礼服被扯开、戴上/摘下标志道具。
- 每个造型写 `episodes`（大致出现的集号区间），方便排生图优先级。
- 原著写了品牌（La Perla、Brunello Cucinelli）→ 圣经里转成**可描述的外观**；品牌名不进视频提示词。

---

## 四、道具（Props）——生命周期表

每件关键道具写：`first_ep` 首次出现 → `states`（集号:状态） → `payoff_ep` 回收集。
- 道具的参考图画**"动作之前"的状态**（信封是封着的、手机屏幕是空白的）。
- 屏幕/标签/文件上的文字一律留空，后期叠字。
- 与人物绑定的标志道具（手绳、挂件）同时写进人物 `signature`，并写清**左右手/佩戴位置**——AI 最容易左右颠倒。
- 三次法则：一件道具至少出现三次（建立 → 强化 → 回收），只出现一次的道具考虑删掉或换成场景陈设。

---

## 五、场景（Locations）

- 主场景 8–14 个，**一次建好、反复回访**。写清：空间锚点（门、窗、楼梯在画面左/右）、单一主光源、白天/夜晚变体。
- 可变物体（门、灯、屏幕、屏风）画"动作之前"。
- 场景之间能合并就合并（四家餐厅 → 一个"餐厅"资产换陈设）。

---

## 六、声线（Voices）

- 有台词的主角：一条固定参考声（`tier: asset`），用户试听确认前都是候选。
- 客串：一句控制词（`tier: prompt`），全剧复用。
- 画外音（V.O.）与设备声（电话、电视、广播）**不进视频模型**，后期配；圣经里给 V.O. 单独标注音色（更近、更轻、无环境声）。

---

## 七、工具

```bash
# 校验圣经 + 与剧本交叉核对 + 生成分集资产表
python3 scripts/bible_check.py adaptation/bible.json --scripts adaptation/scripts/
# 导出为 h3-drama-kit 资产库骨架（cast/props/scenes/acting/voices.json + 生图提示词清单）
python3 scripts/bible_check.py adaptation/bible.json --export-h3 <项目>/library_draft/
```

校验项：ID 唯一、别名不冲突、造型引用的人物存在、道具/造型的集号区间合法；剧本里出现的说话人、`**造型**` 行、`**核心道具**` 行都能在圣经里找到；输出 `05_分集资产表.md`（每集用到哪些人物/造型/道具/场景，每个资产出现几集 → 生图优先级）。

剧本场次头可选加一行造型（写名字或 ID 均可）：
```text
### 场 03. 公寓门厅 · 内 · 清晨
**出场人物**：Ivy, Adrian
**造型**：Ivy=C01-HOME, Adrian=C02-SUIT
**核心道具**：外卖咖啡、旧钥匙扣
```
