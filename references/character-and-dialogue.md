# 人物与对白（Character & Dialogue for Micro-Drama）

> 竖屏短剧没有时间"慢慢认识一个人"：观众在 10 秒内决定喜不喜欢主角，在 3 集内决定追不追。
> 本文是经典编剧理论在 2 分钟短剧里的**压缩用法**。思路参考 Lajos Egri（三维人物、对立统一）、Robert McKee（压力下的选择、言外之意）、Lisa Cron（欲望与错误信念）、Blake Snyder（救猫咪）、Pamela Douglas / Andrew Oberg（连续剧的信息工具）。全部为自写转述；想深挖原理，可配合开源库 [jtydhr88/screenwriting-skills](https://github.com/jtydhr88/screenwriting-skills) 的 `sw-character-conflict`、`sw-dialogue`、`sw-series-structure`。

## 一、人物：五个问题必须有答案

| 问题 | 字段 | 短剧里怎么用 |
| :--- | :--- | :--- |
| 他**想要**什么（外部、看得见） | `want` | 每集的 goal 都是它的一小步 |
| 他**需要**什么（内在，自己不知道） | `need` | 全剧弧光的终点；通常在 70–85% 处被逼着面对 |
| 他**相信的错事**是什么 | `misbelief` | 驱动他一次次做错选择；解开它 = 情感高潮 |
| 他身上**最矛盾**的一组特质 | `contradiction` | 让人物立体：冷血总裁 × 腕上戴 20 美元旧手绳 |
| 他在**压力下会怎么选** | `pressure_choices` | 列 3–5 个关键选择点（集号），人物真相只在选择里暴露 |

### 1. 压力下的选择比描述重要
写"她很倔强"没用；写"她身上只剩 $43，却一分不动 81 万"。人物卡里的每个形容词，都要在剧本里找到一个**代价越来越大的选择**来证明。

### 2. 第一次出场要一个"标签动作"
主角出场的头 5 秒做一件定义他的事（救猫咪：让观众喜欢；或反差：让观众好奇）。
- 好：Wren 发完分手短信立刻拉黑、删记录、把手机扣在被子上——果断、反骨、心虚。
- 差：Wren 走进宴会厅，环顾四周。

### 3. 对手要强，且有自己的逻辑
对手每次出手都要让主角的处境**更坏**；对手觉得自己是对的。言情剧里"对手"常常是男主本人（控制欲）——那就给他一个可理解的理由，并在后段让他付出代价（道歉、放权）。

### 4. 弧光 = 错误信念被一次次挑战
把 `misbelief` 拆成 3 个试炼点（约 25% / 50% / 80%），每个试炼点人物都要做一次更难的选择。

### 5. 配角的功能单一化
短剧配角每人一个功能（闺蜜 = 帮主角说出心里话 + 撞破秘密；损友 = 替观众吐槽男主）。功能重叠的合并。

## 二、语言档案（Voice Sheet）——让每个人说话不一样

| 字段 | 例（总裁） | 例（反骨女主） |
| :--- | :--- | :--- |
| `rhythm` 句长节奏 | 短句、陈述句、很少疑问 | 快、连珠炮、紧张时越说越长 |
| `vocabulary` 用词域 | 金融/合同词：asset、interest、authorization | 文学/游戏叙事词、农场俚语 |
| `catchphrases` 口头禅（≤3） | "little mouse"、"Ms. Hale" | "Technically…" |
| `never_says` 绝不会说 | 不说 "please"（直到道歉弧）；不解释自己 | 不叫他名字（直到 Say My Name） |
| `tells` 说谎/心虚时的破绽 | 停顿后声音放轻 | 补充太多细节 |

**检验法**：遮住说话人名字，读一页对白，能认出是谁在说吗？认不出就改。

## 三、对白：说出口的、没说的、说不出口的

1. **对白是动作**：每句台词都在对另一个人做一件事（逼问、引诱、拒绝、试探）。在表演提示里写这个动作（"逼近""试探"），不写情绪形容词堆砌。
2. **言外之意**：人物很少直说真心。中文潜台词那一行就是写"没说出口的"——英文台词与潜台词完全一样时，这句通常太直白。
3. **信息当弹药**：交代背景只在**冲突中当武器用**时才说出来（"你收了我八十万，喊了我半年老公"——既是交代，也是将军）。
4. **一句话一个意思**：2 分钟、≤220 词，删掉所有寒暄、复述、"我明白你的意思"。
5. **潜台词要能演**：表演提示给演员一个可做的动作（"把杯子推回去"），比"内心挣扎"有用。
6. **AI 视频的限制**：一句台词 ≤ 15 个词更稳；两人抢话、同时说话尽量避免；画面中别人的正脸在别人说话时写"嘴唇闭合"。

## 四、信息管理：四种工具（连续剧的发动机）

| 工具 | 观众 vs 人物 | 效果 | 短剧用法 |
| :--- | :--- | :--- | :--- |
| 悬疑（Mystery） | 观众知道得**少** | 好奇 | 集尾抛问题 |
| 惊奇（Surprise） | 观众和人物都不知道 | 一次性冲击 | 反转钩子，每卷 1–2 次 |
| **戏剧反讽（Dramatic Irony）** | 观众知道得**多** | 紧张、爽、期待爆破 | 言情/马甲剧的主发动机：观众先知道真相，看主角一次次差点穿帮 |
| 悬念（Suspense） | 观众知道危险将至 | 焦虑 | 倒计时、门外脚步声 |

**规则**：分集大纲的 `info_state` 字段就是在管理这四样。一个秘密的"观众知道 → 主角知道 → 公开"三个时间点，要提前在连续性账本里排好；爆破点放在全剧最需要能量的位置（中点、至暗时刻）。

## 五、自查（写完每集过一遍）

- [ ] 主角在本集做了至少一个**有代价的选择**吗？
- [ ] 每个有台词的人，说话方式和他的语言档案一致吗？有人说了他"绝不会说"的话吗？
- [ ] 有没有台词只是在交代信息、没有在冲突里当武器？
- [ ] 本集结束时，信息差（谁知道什么）和上一集相比变了吗？
