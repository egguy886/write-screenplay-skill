# 题材门禁：按题材选用（v4.1）

v4.0 的第 3–7、15 条原来是通用硬门禁，写的全是动作爽剧的套路（苍穹俯冲开场、救猫咪、反派自保、封死退路、装甲车破门、首集当场反杀）。言情、喜剧、悬疑照搬会很别扭：比如都市爱情喜剧第 1 集硬加一个高空俯降，前 3 秒反而慢了。

v4.1 改成**同一个问题、按题材换答案**。每条门禁先写它想防的毛病（各题材通用），再给各题材的过关标准。写剧本前在 `00_改编参数.md` 里填上题材，只检查对应那一列。

| 题材代号 | 包括 |
| :--- | :--- |
| `action` | 动作、奇幻、末世、蒸汽朋克、狼人 / Alpha、修仙、战神 |
| `revenge` | 复仇、逆袭、打脸、马甲掉落、豪门复仇 |
| `romance` | 都市言情、甜宠、契约婚姻、亿万富翁、爱情喜剧 |
| `suspense` | 悬疑、刑侦、惊悚、黑帮 |
| `family` | 家庭伦理、职场群像 |

---

## G1 开场：前 3 秒给观众一个“问题”（原第 3 条）

**防的毛病**：开头只是交代背景，观众没有理由看下去。

| 题材 | 过关标准 |
| :--- | :--- |
| `action` | 可以用大远景、俯降定场（`Crane Down`）立起世界的尺度和阶级高差，但 5 秒内要落到人身上；纯空镜不超过 5 秒 |
| `revenge` | 第一个画面就是羞辱、背叛或身份反差，可以先拍结果再倒叙 |
| `romance` | 直接进一个尴尬或心动的事件：发错短信、醒在错的床上、当众被认错。**不用大远景定场** |
| `suspense` | 谜面先行：一具尸体、一条短信、一个不该出现的人 |
| `family` | 一句让全家安静的话，或一个所有人都看见的物件 |

## G2 先让观众站到主角这边（原第 4 条，救猫咪）

**防的毛病**：主角受难或犯错时，观众还没在乎他。

| 题材 | 过关标准 |
| :--- | :--- |
| `action` / `revenge` | 受辱前给 5–12 秒，让观众看到主角在护着谁、珍惜什么 |
| `romance` | 给主角一个可爱的毛病或较真的怪癖（数数、做表格、四平八稳地说荒唐话），让观众先笑，再心疼 |
| `suspense` | 给主角一个只有他注意到的细节，让观众跟着他的眼睛走 |
| `family` | 给一个具体的付出动作（替人收拾、默默垫钱），不靠台词自夸 |

## G3 阻力方的理由要成立（原第 5 条，反派自保不降智）

**防的毛病**：反派或阻力方做蠢事，只是为了让剧情继续。

| 题材 | 过关标准 |
| :--- | :--- |
| `action` / `suspense` | 反派绝不拉自己陪葬，每一步都先保自己，再害主角 |
| `revenge` | 加害者有体面的理由，也有守得住的利益，打脸才有分量 |
| `romance` | 情敌、家长、未婚夫也要有自己的道理和体面，不能只为拆散而存在；最好的阻力是一个“好人” |
| `family` | 每个人都觉得自己是对的 |

## G4 观众一定会问“为什么不……”，先替他回答（原第 6 条，封死退路）

**防的毛病**：观众心里冒出最简单的解法（逃走、报警、直接说清楚），剧本却没理它。

| 题材 | 过关标准 |
| :--- | :--- |
| `action` / `suspense` | 用画面里看得见的筹码堵死退路：人质在对方手里、门被焊死、电话没信号 |
| `revenge` | 交代主角为什么现在不能撕破脸：证据、时机、亲人 |
| `romance` | **误会和隐瞒类必查**：“他为什么不直接告诉她？”“她为什么不直接问？”要给一个观众认可的理由（承诺、怕失去、说了会伤到第三个人），并在剧里**至少说出来一次** |
| `family` | 交代为什么不能直接走：钱、孩子、病 |

## G5 换地方要交代怎么到的（原第 7 条，三明治过渡）

**防的毛病**：上一场穿浴袍，下一场全副武装出现在另一个城市。

| 题材 | 过关标准 |
| :--- | :--- |
| `action` | 大空间跳转前有传导媒介（警报、通信），后有到达段（车队冲进雨里、人踏进现场） |
| 其他 | 一拍就够：车停下、门打开、手机上的地址、一句“到了”。换装要在画面里交代 |

## G6 首集要给一个兑现（原第 15 条，首集反杀）

**防的毛病**：第 1 集只铺垫，观众没尝到甜头就走了。

| 题材 | 过关标准 |
| :--- | :--- |
| `action` / `revenge` | 首集施暴的人在首集末被主角亲手讨回；中层反派再登场时，筹码要升级 |
| `romance` | 首集给一次心动兑现：一个吻、一句告白、一次被护住，然后马上抛出更大的麻烦 |
| `suspense` | 首集破一个小谜，同时露出大谜的一角 |
| `family` | 首集里有一个人第一次说出真话 |

---

**用法**：这六条都是**题材门禁**，只对选定的题材检查；没填题材时只按“防的毛病”那一句自查。要机器提示时，给 `script_lint.py` 加 `--genre action|revenge|romance|suspense|family`。目前机器只检查 G1：`action` 题材 EP001 开头缺定场镜头时提示，`romance` 题材 EP001 开头用了大远景或航拍定场时提示。其余几条靠写作时自查和看懂测试。

题材钩子（集尾怎么断）另见 `episode-hook-system.md` 第五节。
