# 集尾钩子系统（Episode Hook System）

> 目标：让每一集都像连载小说的章节一样，**最后一个画面逼观众点下一集**。
> 钩子不是"出事了"，而是**一个问题被提出、答案即将出口的那一刻**。

---

## 一、八种钩子（type 字段取值）

| type | 中文 | 定义 | 言情 / 都市示例 | 动作 / 悬疑示例 |
| :--- | :--- | :--- | :--- | :--- |
| `reveal` | 揭示 | 一个真相露出**一半** | 手机弹出转账附言："Answer your phone." | 档案照片上的人是主角自己 |
| `threat` | 危机迫近 | 危险/穿帮即将降临 | 门外传来他的脚步声，她的两个账号都还登录着 | 枪口抵上后脑 |
| `choice` | 抉择 | 主角手指悬在不可逆的按钮上 | 拇指停在 "Send" 上，消息是分手长文 | 红线还是蓝线 |
| `reversal` | 反转 | 局面在最后一秒翻转 | 她正在吐槽的"老男人"就站在她身后 | 盟友把枪口转向主角 |
| `almost` | 情感临界 | 吻 / 告白 / 认出 差一点发生 | 他俯身，停在离她嘴唇一指的地方："Say stop." | 两人终于要相认，警报响了 |
| `line` | 金句 | 一句话把对方将死 | "You've been texting me for months, Miss Grant." | "I was never on your side." |
| `question` | 悬问 | 抛出一个具体的谜 | 收发室一条署名 "Ivy" 的钻石手链，寄件人空白 | 尸体手里攥着主角的照片 |
| `arrival` | 闯入 | 关键人物在最坏时机出现 | 相亲餐厅，他在邻桌坐下 | 门被踹开，失踪的哥哥站在门口 |

另有 `ending`（结局）只允许用在最后一集；最后一集也可以用一个小钩子开续季。

---

## 二、钩子强度（level 字段）

| level | 用在哪里 | 标准 |
| :--- | :--- | :--- |
| `small` | 普通集 | 本集问题升级，观众想知道"然后呢" |
| `mid` | 每 4–6 集一次、每卷结尾 | 关系或局势发生不可逆变化 |
| `big` | 付费墙、中点、至暗时刻、高潮前 | 全剧级别的信息差爆破或决裂 |

**钩子阶梯（Hook Ladder）：** 至少每 10 集一个 `big`；每卷最后一集 ≥ `mid`；付费墙那一集必须 `big`。

---

## 三、写钩子的七条规矩

1. **切在答案出口前 / 动作落地前。** 巴掌停在半空、消息"已读"还没回、门开了一半、他刚说出第一个字。答案一出口，钩子就死了。
2. **最后一个画面要具体、能拍。** 写成画面或一句台词，不写"悬念升级"这种描述。
3. **下一集前 10 秒必须回钩。** 兑现一半，再立新问题。不回钩 = 骗点击，观众会弃剧。
4. **禁止假钩子套路。** "原来是梦""原来是误会"全剧最多 1 次；每 5 集最多 1 个"软兑现"（钩子的答案比预期轻）。
5. **类型轮换。** 同一 type 不连续超过 2 集；全剧每种类型都要出现。
6. **钩子来自人物，不来自巧合。** 好的钩子是主角自己的选择或谎言造成的后果。
7. **最后 1–1.5 秒是有内容的停留。** 反应镜头、道具特写或定格表情，配合下游 AI 出片"片尾不稳"的特点。

---

## 四、从原著里找钩子

1. 先看 `chapters.json` 里 `hook_strength ≥ 4` 的章尾 → 首选集尾。
2. 两个强钩子之间相隔 > 3 章 → 中间浓缩，或把下一个揭示**前移**到本集末。
3. 原著钩子是内心独白（"我突然意识到……"）→ 外化成画面：手机屏幕、道具、对方的一句话。
4. 一章里有两个强节拍 → 可以拆成两集的尾巴（但该章要压短）。
5. 没有天然钩子的过渡章 → 用 `question` 或 `arrival` 制造：把下一场戏的第一个画面提前放到本集最后。

## 五、题材钩子库

### 言情 / 总裁 / 马甲（非暴力型，别照搬打脸剧的耳光枪口）
- 手机通知类：陌生号码来电 / 转账附言 / "Seen" / 对方正在输入… 然后停了
- 身份穿帮类：两个账号同时亮着 / 他念出她的小名 / 他手腕戴着她送的东西
- 距离类：电梯门合上前他伸手挡住 / 他搬到了对门 / 他在邻桌坐下
- 宣示类："She's with me." / 他当众叫出她的全名 / 他替她签了字
- 临界类：差一点的吻 / 差一点说出 "I know" / 她刚要坦白，他先开口

### 复仇 / 打脸
- 身份揭晓前一秒（黑卡落桌、车队到达、对方瞳孔放大）
- 证据袋/报告刚撕开封条
- 反派说出狠话，背后站着主角真正的靠山

### 悬疑 / 动作
- 发现物证 / 有人在暗处 / 计时器开始倒数 / 盟友背刺

## 六、开场回钩（open_payoff）的写法

| 上集钩子 | 本集前 10 秒 |
| :--- | :--- |
| reveal（真相露一半） | 露出另一半，同时抛出新的后果 |
| threat（危险迫近） | 危险落地，但结果出乎意料（更糟或峰回路转） |
| choice（手指悬停） | 按下去 / 没按，并立刻看到代价 |
| almost（差一点） | 被打断 / 继续，但关系从此改变 |
| line（金句） | 对方的反应镜头 + 第一句回击 |
| arrival（闯入） | 来人的第一句话 |

回钩画面应与上集最后一个画面**同一时空、换景别硬切**（例如上集停在近景，下集从反打或特写开）。
