# 小说与世界观转剧本核心引擎（Novel-to-Script Engine v5.0）

## 一、 小说思维与剧本思维的根本对立

许多通用模型在把小说改成剧本时，最容易踩四个致命大坑：
1. **把多个子空间揉进同一场戏**（如把“女囚室 + 走廊 + 隔壁木牢”合并为一场，导致下游 AI 视频共用同一张场景图，人物像原地凭空刷新）；
2. **把原著最精彩的反差与伏笔删进“潜台词括号”**（`（中文潜台词：…）` 根本不会进视频提示词，观众既听不见也看不见）；
3. **靠画外音 V.O. 硬撑，关掉声音后画面动作因果断裂**（如没先拍走廊火光逼近，女主刚坐起来又无故躺下）；
4. **为了硬卡 120s/180s 秒数砍掉动作过程**（导致上一秒空手、下一秒凭空变出匕首）。

| 维度 | 小说（Novel） | 电影级可拍剧本（Screenplay v5.0） |
| :--- | :--- | :--- |
| **空间粒度** | 一段文字可连跨牢房、走廊、隔壁三处 | **一子空间一场戏**（跨过门/栅栏/拐角立即拆新 `### 场 NN.` 并写过渡动作） |
| **站位坐标** | 读者自行想象谁在门里谁在门外 | **每场头部写死 `**开场站位**`**（隔断物 + 内外/画左画右/姿态/朝向） |
| **心理与戏眼** | 允许大段心理博弈与全知旁白 | **严禁藏进潜台词括号**！必须转化为现场可听台词或可见物理微动作 |
| **动作与道具** | 一笔带过“反杀后顺走钥匙和短刀” | **静音可读 + 道具出处守恒**（先拍腰间挂刀钥 → 反杀压制 → 伸手从腰间拔走） |
| **时间测算** | 3000 字章节阅读仅需 5 分钟 | **按真实语速（中 3.8 字/s、英 2.5 词/s）+ 动作节拍（3.2s/拍）诚实定长** |

## 二、 四步前制转译铁律（Pre-Production Translation Rules）

### 1. 物理子空间拆场与过渡桥（Sub-space Split & Transition Bridge）
- 动笔前先列出本章所有**具体子空间**：例如寒山矿洞第一章实际包含 `① 女囚室`、`② 牢外走廊`、`③ 隔壁月光木牢`、`④ 矿洞赌酒窄道`、`⑤ 洞口寒林雪径` 5 个独立子空间。
- 每个子空间独立成场，并在场尾/场首写清**身体如何跨过边界**（如：蹿出铁栅门进入走廊 → 沿走廊跑两步顿住望向隔壁木栅）。

### 2. 每场头部锁定 `**开场站位**`（内化 `novel-staging`）
- 在每场 `**核心道具**` 下方写明：**锚点隔断物 + 每个人在隔断哪一侧、画左/画右、初始姿态与朝向**。
- 正例：`**开场站位**：以画左木铁栅门为界——矿匪甲与疤脸老四同处栅栏外走廊石桌旁面朝牢内；桑晚独处栅栏内右墙干草堆闭目侧卧。`

### 3. 原著戏核与跨场呼应守恒（Payoff & Echo Preservation）
- 凡是集尾反转依赖的前置信息，必须在前面场次用**现场视听实据**立住！
- 正例：集尾要揭示“赌桌三具结霜无头尸”，前场窄道就必须真切拍出**三名矿匪围着火盆木桌摇骰叫骂“三个六豹子，拿钱来！”**，再拍袖中勾指灭灯与黑暗中三声“咔嚓”冰裂脆响。

### 4. 内心戏外化与“静音可读”自检（Silent-Readable Test）
- 写完一场戏，把所有台词和 `V.O.` 遮住，只读 `△` 动作行：
  - 每次姿态反转（如坐起→躺回装睡、后退→折返开锁），前一行 `△` 是否有明确的视觉/听觉触发源？
  - 每次手里多出一件道具，前文是否交代了它原本挂在谁腰间、放在哪张桌上？
